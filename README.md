# TSA Lost & Found Pattern Analysis

An interactive airport intelligence platform built with **Next.js 15**, **Python (Pandas)**, **TypeScript**, and **Plotly** to analyze **218,489 TSA Lost & Found claims** across U.S. airports (2002–2017).

**Live Demo:** https://tsa-lost-found-pattern-analysis.vercel.app/

## Features

* Executive Overview Dashboard
* Operational & Geographic Dashboard
* Financial & Pattern Analysis Dashboard
* Interactive U.S. Airport Map
* Operational Risk Score (0–100)
* Cross-dashboard filtering
* Dark & Light mode
* Exportable reports

## Tech Stack

* Next.js 15
* TypeScript
* Python (Pandas & NumPy)
* Plotly.js
* Tailwind CSS
* Vercel

## Run Locally

```bash
git clone https://github.com/sadaf2730/tsa-lost-found-pattern-analysis.git
cd tsa-lost-found-pattern-analysis
npm install
python python/export_json.py
npm run dev
```

Open `http://localhost:3000`.
